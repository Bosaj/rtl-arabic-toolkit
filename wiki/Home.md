# Welcome to the RTL Arabic Web Layout Toolkit & Audit CLI Wiki

Welcome to the official documentation for **RTL Arabic Web Layout Toolkit & Audit CLI** (`@Bosaj/rtl-arabic-toolkit`).

## Project Overview

Comprehensive developer toolkit and automated audit CLI to detect, prevent, and fix Right-to-Left (Arabic) layout and BiDi bugs in modern web apps.
